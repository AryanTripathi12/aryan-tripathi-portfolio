# Aryan Tripathi — Portfolio

An original, responsive static portfolio for GitHub Pages. It has no build step or dependencies: open `index.html` in a browser to preview it.

## Personalize it

1. Your portrait, email, GitHub, and LinkedIn are already included.
2. Add links to live demos or repositories to the project arrow buttons if you have them.
3. To use a different portrait later, replace `assets/aryan-tripathi.jpg` and keep the same filename.

## Deploy on GitHub Pages

1. Create a new GitHub repository, for example `aryan-tripathi-portfolio`.
2. Upload every file in this project, preserving the `assets/` folder.
3. On GitHub, open the repository **Settings** → **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose the `main` branch and the `/ (root)` folder, then press **Save**.
6. Wait a minute or two. GitHub will show the published URL in the Pages settings, typically `https://YOUR-USERNAME.github.io/aryan-tripathi-portfolio/`.

For a site at `https://YOUR-USERNAME.github.io/`, name the repository `YOUR-USERNAME.github.io` instead.
